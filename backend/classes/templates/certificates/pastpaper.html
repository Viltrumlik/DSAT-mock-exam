{% comment %} Pastpaper certificate — two A4 landscape pages. Written as a real Django template with real variables, deliberately unlike its neighbours. `ranked.html` and `norank.html` are ~600 KB design exports carrying fixed placeholder strings ("Aziz Karimov", "740"), which the renderer replaces by walking text nodes — a technique that exists only because nobody could edit those files. Nothing here needs that: the data arrives as context, so a wording change is a wording change rather than a hunt for the exact string in a minified bundle, and the two injection maps (backend and React) that had to stay in step with each other do not exist. The design is distinct from the midterm certificate on purpose — the school asked for the same thing with a different face. Where the midterm cert is a landscape card with a vertical rail and a gold seal, this is a centred column on a deep field with the score as the single loudest element, and a second page nobody else has: the error report. Page 2 only renders when there is something to review. A student who got everything right is handed a certificate, not a blank page headed "What to work on". Fonts are system stacks, not embedded webfonts. That costs a little polish and buys a file a tenth of the size that cannot render with jammed advance widths on the prod Linux box the way an embedded Type-3 font can (see the --font-render-hinting note in certificate_html_pdf.py). {% endcomment %}
