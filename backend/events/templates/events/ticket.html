{% comment %} The event ticket, captured as a PNG by headless Chromium (events/ticket.py). Its fonts are embedded, not a webfont fetch: `font_faces` is a set of `@font-face` rules lifted from the certificate template (which already ships them) and rewritten to point at inline `data:` URIs, so Chromium never needs a network request to lay the text out — text in 'Plus Jakarta Sans', the code in 'Space Mono', each followed by a system stack as a fallback. The QR and the logo are inline data URIs too, for the same reason: the page is handed over via set_content and has no base URL to resolve anything against. The card's height is a minimum, not a fixed size: an extreme title, place or name pushes it taller rather than getting clipped out of the element screenshot (events/ticket.py's `_render_png_chromium` shoots `#ticket` itself, whatever height it ends up). {% endcomment %}
